The TOON ratchet gains a second dimension: the wire, not only the file (#2948). The guard that keeps this repository on TOON was named for its own limit — it walked `apps/` and `packages/` for JSON **file** reads and writes and had no opinion about a socket. That is why the daemon's entire request/response wire was JSON while every file it wrote was already TOON (#2947), and why nobody noticed until an operator read the socket by hand. Fixing the wire without extending the ratchet would have fixed today and left tomorrow open: the next socket someone adds would be JSON for exactly the reason this one was — nothing said otherwise.

**A `JSON.stringify` handed to a wire write, or a `JSON.parse` of a payload read off one, now fails the same way a JSON file write does.** A wire is a receiver whose name says so — `socket`, `conn`, `stream`, `peer`, `ws`, a child's `stdin` — and the read half is traced through the buffer that actually carries a frame: the chunk a `data` handler receives, accumulated with `+=`, sliced at the newline, then parsed. `stdout`/`stderr` are deliberately not wires: a terminal is a rendering surface, and the encoding a CLI prints in is the CLI's own contract (#2946). The failure names the encoder that replaces the offence — `encode`/`decode` from `@reddb-io/toon`, and `encodeWireFrame`/`decodeWireFrame` for a socket frame — instead of only naming the offence.

**Two things stay green by design, and a fixture proves each.** Quoting a value inside an error message is legibility rather than a payload, so a `JSON.stringify` interpolated into prose or thrown in an `Error` is not reported; a site reached only behind an explicit `--json` flag is a caller who asked for JSON, and the mandate governs the default. The new dimension seeds two `external` entries — a foreign CLI that reads its request as JSON on stdin, and Chrome DevTools Protocol frames, which are JSON by specification — and nothing else: the sockets it would otherwise have caught were converted first. Like the guard it joins, the baseline only ever shrinks.
