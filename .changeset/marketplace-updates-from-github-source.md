A marketplace can only update from the source it was registered with, so the installer now registers the Claude and Codex marketplaces from the GitHub source instead of the release snapshot it downloaded. Registered from a directory, `plugin marketplace update` re-read that unchanging snapshot forever: every update succeeded while advancing nothing, and a machine stayed on its install-day version no matter how many releases shipped. Registered from `reddb-io/red-skills`, the CLI's own update flow pulls origin and reaches every future release with no re-install. The directory form survives as the explicit `--local-marketplace` opt-in for offline and dev installs, where pinning to the downloaded snapshot is the point. A machine installed before this change is healed by re-running the one-liner: the installer reads the registered source, and a Directory-sourced `red-skills` marketplace is removed and re-added from GitHub. `/red-doctor` reports the registered source per host CLI and flags the frozen shape read-only; `--fix` repoints it after confirmation, and never repoints a registration it could not read, because replacing one would discard whatever the operator configured.
