The host daemon now derives live metrics over rolling 1h and 24h windows from state it alone holds, and every surface reads them off the one aggregate payload it already fetches. Tokens/min and tools/min come from the deltas of the Worker vitals the heartbeats carry — summed per Worker so two unrelated counters are never subtracted, spanned over the union of the samples so concurrent Workers are not divided by more wall-clock than the machine lived through, and treating a counter that dropped as one that restarted rather than as work undone. Issues per hour comes from the Worker outcomes on the host event lane, seeded at boot from the lane a predecessor wrote so a restart mid-day does not report a machine that finished nothing. Usage share by runner and by model counts each Worker once under its newest attribution, beside a count of the Workers no project attributed at all — a share list that silently dropped them would report 100% of a machine while describing half of it. A window with no data reports absence with a stated reason and never a zero, and a window names each source that had nothing to answer with, so "the sampler is down" and "the machine is quiet" stop producing the same null. The daemon aggregates; surfaces print, and nothing re-derives.
