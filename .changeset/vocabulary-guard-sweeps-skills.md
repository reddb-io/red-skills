The vocabulary ratchet sweeps the shipped skills

**A skill is source for the reader who has no source.** The domain-vocabulary
ratchet swept four source trees and no skill, so `/red-doctor` went on telling
operators that "ADR 0143's one versioned Castle resident per canonical project
owns engine state" long after the daemon absorbed it, and the liveness doc
credited a reaper to the Demand producer. Both compiled nothing, passed every
guard, and taught the wrong architecture to every agent that read them.

`plugins/{dev,memory,brain}/skills` now sweep with the same four retired
ownership phrases and the same allowance mechanism. Markdown is read as prose:
`<!-- … -->` is its only comment, because a `//` strip would swallow everything
after the first URL on a line and let a retired owner hide behind a link. The
generated `packaging/pi/*/skills` mirrors stay out of the sweep — reddening a
projection teaches the next worker to edit the copy.

The two drifted texts are repaired in the same change.
