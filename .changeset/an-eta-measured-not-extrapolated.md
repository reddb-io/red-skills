The display record carries an execution time, a context figure and an ETA, and the ETA is measured rather than extrapolated. None of the three existed in the contract, so the dashboard could not have shown them however well the rest of the record was populated. `started_at` and `context` land as fields; `elapsed` deliberately does NOT — two surfaces each publishing their own would disagree about now the moment one sampled a beat later, so the render subtracts the start from the payload's own `generated_at` and the two densities cannot drift. The ETA's prerequisite was the missing measurement: `.red/state/castle/history.toonl` records one `duration_s` per terminal issue-level event, so the finest answer it could give was "issues like this took ~22 min" — useless to a progress bar and silent about a Worker three minutes into `validating`. A new durable lane, `.red/state/castle/phase-durations.toonl`, records one row per phase a Worker LEAVES, and the estimate is the median of the current phase plus the median of every phase ahead, scoped to the Worker's own runner where it has enough history. The median rather than the mean because one hour-long gate-lock wait drags a mean into fiction; and a phase short of samples refuses the WHOLE estimate rather than publishing a floor, because a partial model prints with the same confidence as a complete one. A linear extrapolation from `phase_index/phase_total` is refused outright — it moves with the bar, so it looks precise while being systematically wrong — and the refusal is structural rather than conventional: no function in the estimator takes an index or a total, so the wrong estimate is inexpressible in its signatures. Measuring lives on the beat the castle lane bridge already keeps, which is the one place that sees `current.phase` whoever stamped it: five writers set it today and instrumenting each would be five chances to add a sixth nobody measures. The bridge also publishes the whole display record there, built by the project because every field in it is castle semantics the daemon may not carry (ADR 0130 rule 3) — the daemon stores it without reading a field, and a surface prints what it was handed. `macroPhase`/`isLandingPhase` became one namer for a fold the lifecycle bar, the mirror title and the duration model each derived separately, and `context_tokens` joins the worker state as the last turn's input side, a level rather than the cumulative total beside it.
