A registered project now produces a Worker, because the daemon can finally ask about it. The queue poll was wired and disconnected in two places at once. The registration handed the host the project's own JSON selector shape — and the daemon, which carries a selector and never reads one, dutifully asked the tracker to search for `{}`, an answer about nothing on every project forever; a registration now carries a tracker query built from the repository its work lives in plus every facet a query can express, with the numeric facets it cannot express named in a warning rather than silently dropped. Underneath it, a daemon nobody handed a transport returned before it asked, so an unconfigured poll looked exactly like a host that had counted nothing yet: a valid registration, a stated target, a full queue and zero Workers, with every surface reporting health. An unconfigured poll is now an outcome of its own, reported on each registration with the reason of whoever would have armed it, and the credential is read from the tracker CLI's stored login when the environment names none — which is the state an auto-spawned daemon inherits on a developer machine that was authenticated the whole time. A rate-limited poll, a failed one, a drained queue and an unasked one stay four distinguishable facts, and N registered projects still cost one tracker request per interval.
