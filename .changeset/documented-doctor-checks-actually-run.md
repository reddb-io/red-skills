Seven `/red-doctor` checks that the SKILL.md declared, a docs test asserted, and unit tests exercised were reachable from nothing: the doctor command imported none of `hook-doctor`, `runtime-doctor`, `host-binary-doctor`, `red-taxonomy-doctor`, `ask-red-router-doctor`, `dependency-edge-doctor`, or `unlanded-docs-doctor`, so it reported clean on dimensions it never examined. Every one of those classifiers is pure and injected-facts-only by design, which is exactly how they stayed green in isolation while examining nothing in production — a naming contract is not a wiring contract. The doctor now collects the facts each one needs (`.red/config.yaml` backpressure and hook declarations plus the `.red/hooks/` tree, the bundle cache keyed by each plugin's installed version, the catalog `tq` pin against the recorded and observed ones, both ADR 0094 dependency surfaces, the dev manifest against the ask-red router, the `.red/` tree against ADR 0098's lane registry, and the shared ADR 0092 Docs Sweep) and renders every finding in both the human scorecard and the TOON form. Read-only semantics are unchanged: no command is executed, no bundle fetched, no label or edge touched, no file moved. Each check degrades on its own — an unreadable half names itself in a note rather than blanking the other six — and nothing is capped silently: a dependency-edge compare that did not read every open Ticket prints which ones it skipped. The docs contract now asserts REACHABILITY by walking the command's import graph, so a classifier the SKILL.md names and nothing imports fails the test that used to pass on the naming alone, and a posed repo per check proves the documented finding comes out the end of the command.
