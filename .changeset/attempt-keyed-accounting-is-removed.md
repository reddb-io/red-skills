Attempt accounting is removed from the supervisor, and the extinction ratchet now catches the leftover (#2850). ADR 0130 extinguished the Attempt and deleted its record and its retention rule, but `supervisor/attempt-accounting.ts` survived and was still imported by `supervisor.ts`, `tick.ts` and `reaper.ts`, so the live supervisor kept per-Attempt resource accounting for a unit of work that no longer exists. Sampling itself was never the leftover — the Attempt-keyed IDENTITY around it was. The module is now `supervisor/worker-accounting.ts` (`workerUsage`, `sampleWorkerPeakRss`) and the budget vocabulary it decides against is `core/worker-budget.ts` (`WorkerUsage`, `WorkerBudgets`, `WorkerBudgetBreach`, `resolveWorkerBudgets`, `evaluateWorkerBudgets`, `WORKER_BUDGET_*`), keyed to the Worker — which is the unit that survived, because a Worker already IS one Worker × one Ticket × one try. The `afk.attempt.budget.*` config keys and the `RED_AFK_ATTEMPT_*` env overrides deliberately keep their published spelling: they are the operator contract an existing `.red/config.yaml` already carries, and renaming a key is a breaking change of its own rather than a rename.

The second half is why this recurred at all: **the ratchet did not catch it.** `extinct-source-guard.ts` scanned for reintroduced SOURCES — a reader reaching for a removed lane, contract or identifier — and `attempt-accounting.ts` imported nothing extinct, so the scan saw a clean file while a live module still carried the dead noun in its own name. The guard now has a second dimension: `EXTINCT_NAMES` matches a module basename and every identifier and path token, so a module or symbol NAMED for an extinct concept fails exactly the way a reintroduced source does — same baseline, same message, with the dimension named (`module named for extinct concept`) so the failure says whether to change an import or rename the module you are standing in. Each entry pairs the noun with what it owned rather than reddening the bare word, because the words did not go extinct — the concepts did: an ordinary retry of a push is still an attempt, `CastleAttemptStatus` is still a live envelope attribute, and `FLEET_USAGE` is still the CLI's help text. The removed module is kept verbatim as the test fixture that proves the dimension, including the assertion that with the name inventory switched off it is green — which is exactly how it survived.
