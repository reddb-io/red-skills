The GitHub balance is now asked rather than accumulated, and `@reddb-io/github` gains the three pieces that make a spent budget survivable. A ledger the daemon totals from its own calls is blind by construction: the daemon is host-scoped, the quota is per token and therefore cross-host, so an operator running four machines on one token would have four daemons each reporting three quarters of a fiction — measured, and only visible because three of the four were switched off mid-session. `GET /rate_limit` returns the whole token's true remaining budget across every machine and costs nothing (six consecutive calls moved `core` by zero), so `balance.ts` parses it, decides the next poll from the balance itself — rare above half, tightening as it falls, waiting for the reset once spent — and answers whether one call may spend, against the named pool only. A reserved band holds the last tenth for work that must not fail: a claim that cannot be written is a Worker that declines its issue, and a finishing Worker must be able to say so, while convenience reads are refused. A stale reading refuses convenience and admits essentials, because refusing everything would let a dead poller halt a healthy machine. `cache.ts` keeps an answer with its age attached and returns a stale entry rather than dropping it — dropping it leaves a caller with nothing exactly when the network or the budget is why it went stale — with TTLs chosen by rate of change rather than importance. `aliased-query.ts` builds one query spanning every registered repository, which ADR 0130 decided and nothing had built; it is flat in requests and NOT in node points, and a repository that does not answer is omitted rather than reported as zero, because a renamed or newly private repo rendering as an empty queue is the same lie queue discovery already refuses.
