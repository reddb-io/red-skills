A Worker now runs on the same node the engine that launched it runs on, instead of hunting for one on a PATH that was never going to hold it. A Worker is born into a sanitized, system-shaped PATH — the init system's under a transient unit — so on a version-manager host (mise, nvm, asdf, volta), where node lives only under the manager's install root, six of the seven required host tools resolved from `/usr/bin` and node alone went missing: the boot prereq probe reds out with `missing required host tools: node` while the very process printing that sentence is a node process holding the absolute path of its own interpreter. The daemon now prepends `dirname(process.execPath)` to the PATH it hands every Worker, on the transient unit and on every degraded backend alike, moving the directory rather than duplicating one already there and keeping a client-declared PATH behind it; the engine adopts the same directory at its own front door, so every child it spawns — the agent CLI, git hooks, `command -v node` — resolves that node too; and the probe resolves node from the engine's interpreter when PATH does not carry it. A tool that is genuinely absent still fails, and now says which directories were searched, with node's failure naming the engine interpreter that was the expected fallback — one read instead of a forensic session.
