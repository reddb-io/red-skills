# RedSkills Context Index

RedSkills now uses multi-context domain documentation. Start at
[CONTEXT-MAP.md](./CONTEXT-MAP.md), then open the context that matches the
plugin or workflow you are changing.

Do not add glossary terms to this compatibility file. Add them to:

- [Dev context](./contexts/dev/CONTEXT.md) for the `dev` plugin and engineering
  workflow language.
- [Memory context](./contexts/memory/CONTEXT.md) for the `memory` plugin,
  RedDB-backed graph language, and persistent agent memory language.
