# packages/shared

Per [ADR 0034](../../.red/adr/0034-monorepo-src-domains-with-per-plugin-bundles.md) (layout relocated to root `apps/`+`packages/` by [ADR 0060](../../.red/adr/0060-root-apps-packages-with-pnpm-catalog.md)), `packages/shared/` holds code common to two or more `apps/*` plugins (currently `dev` and `memory`); extraction is demand-driven and, where the author already ships a fitting published package, that package is adopted rather than re-implemented. The first extraction is the **shared CLI argument layer** (`args.ts`, re-exported from `index.ts`): a thin, dependency-light wrapper over the published `cli-args-parser` that exposes a schema-driven `parseFlags(argv, schema)` returning a typed `{ values, positionals }` result and a minimal `routeCommand(argv, schema)` command router, establishing the one CLI-parsing convention every plugin consumes instead of hand-rolling its own flag scanning.
